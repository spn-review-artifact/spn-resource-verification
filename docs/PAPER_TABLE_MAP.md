Run each Python filename above from `src/`, for example
`python -B src/verify_mixcolumn.py`. Definitions and hand-derived wire or
lifetime presentations are identified as such; this map does not imply that
every manuscript cell is generated by a single program.

## CNOT conventions

Table 1 counts CNOTs outside temporary-AND gadgets. Table 14 adds the stated
4T lowering budget. LIGHTER-R's native X/CNOT/Toffoli counts precede both the
clean wrapper and gate lowering. Consequently, those native CNOT counts are
not interchangeable with Table 14's lowered clean-circuit CNOT estimates.

## Evidence coverage

The six primary S-boxes have released forward and inverse witnesses. The two
additional Table 1/Table 14 rows use the historical seed-0 RECTANGLE and KLEIN
records. Their conversions are checked against those records, with no claim
of gate-file replay for these two rows. `verify_table14.py
--require-all-witnesses` explicitly distinguishes that coverage.
